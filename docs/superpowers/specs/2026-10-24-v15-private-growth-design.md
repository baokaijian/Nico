# V1.5 私人成长体验设计

基线：master 53a6b7b（V1.4.1），继续用户已授权的V1.5四阶段建设及验证后推送上线。复用四入口、QuickEntry、技能/目标/报告/赛事/时间轴/日历；不重复开发。无AI服务、儿童排名、天赋预测或运动量奖励。全部新实体私有，不调整既有公开授权。

## 阶段1：儿童工作区与安全合同

家长账号菜单→孩子的成长页设置：主题、昵称/标题、精选私有照片（最多12张，照片类型兼容photo/image），保存使用现有成长版本/history/CAS/幂等。明确“进入后清除本设备家长凭据，交还家长需重新登录”。已确认技能、同项目池长有效PB、已确认里程碑及故事为只读摘要；技能进步仅有兼容标准的已确认前测与真实等级变化时标识。

开启时后端派生child会话，最多15分钟且不超过父会话有效期；保存父token哈希、childViews ID/版本。每次请求复核父会话、账号与配置版本，撤回/删除/更新配置立即拒绝。云持久会话支持跨冷启动；本机Cookie会话等价保护。客户端替换令牌并清空家长事实、草稿身份与旧响应；不把父令牌藏在其他浏览器存储中。儿童角色只允许session/logout、child-view、选中照片、child-reflections新建；其余私有读写403，匿名401。公开访客仍只使用原白名单。

孩子可选本次已发生训练（摘要最近30条，仅日期与内容，不含训练量压力）或不关联，手工选心情和一句话。POST只接收这些字段，后端强制待确认，不接受等级/成绩/确认元数据；日期必须真实合法，关联必须在可见列表。请求ID稳定，重试同内容返回原记录、不同内容冲突。父会话撤销及过期不允许继续提交。家长在设置同屏独立确认/回收，不复制到训练事实。确认感受不自动公开或变成纪念册发言。

视觉：暖纸#FBF8EF、海水#176C79、墨绿#173C43、日光#DFB965、植物#668A68；系统中文字体，主题大字、正文18px、大触控，静态水波插画为主要识别点。手机纵向“主题→已确认进步/PB→照片→感受→里程碑/故事”，平板双栏。不展示系统审计原文，不用排行榜、连续天数压力或训练量奖励。

## 阶段2：纪念册

分析复盘→年度纪念册。选择已确认年度报告，保存时由后端冻结reportSnapshot和选定照片/影像元信息；原报告及原事实不变。字段：title/year/reportId/theme/parentMessage/childMessage/sectionOrder/selectedMediaIds，来源快照、作者、时间、版本及状态由服务器维护。sections固定白名单可上下移动（封面、主题、成绩技能、比赛里程碑、精选影像、寄语、来源），不能改写事实。允许待确认叙事编辑，确认后只读；变更需另建版本化草稿，不静默刷新已确认来源。

来源后来改变时提示过期；可保留生成时事实并带状态导出，确认要求基线仍有效。PDF浏览器本地生成，使用pdf-lib/fontkit与可再分发的OFL中文字体，照片只通过现有私有读取接口嵌入；视频仅索引，无公共URL。下载失败不影响已保存纪念册。PDF分页/中文/来源/确认标识经隔离生成、提取与渲染检查；真实设备/打印人工待验。

## 阶段3：档案归档

管理设置→私人年度归档。年度选择、报告选择（可用已确认年度报告；不存在时仅生成明确标为未确认的即时事实摘要，不写业务库）、媒体/证书显式选择，显示预估大小与权限提示。归档格式nico-year-archive-v1，与可直接整库恢复的nico-backup-v1区别清楚；不以年度子集覆盖正式完整档案。

JSON包含年度记录、直接/递归关联的支持记录及版本/相关历史、关联清单、缺失引用与排除清单；周期外支持记录明确标识，不当年度新事实。CSV保留timeMs与真实量，未知留空、防公式注入。PDF复用同一生成器。原片按ID命名，不用儿童姓名/位置作文件名。所有文件SHA256、ZIP CRC32与文件数量列清单；manifest自身不自哈希，另导出校验根清单。

每个原文件≤50MB，每卷≤100MiB，顺序鉴权读取、失败最多重试2次、可取消；媒体缺失/越权不能假装完整成功，保留进度可只重试失败项，跨账号/退出立即失效。下载分卷以控制浏览器内存，不把归档存到Pages或公开桶；大于单文件上限给出明确限制，不静默裁剪。JSON/CSV/PDF/关系与ZIP通过隔离独立解包/校验，真实大型媒体与设备内存体验仍待人工验收。

## 阶段4：阶段驾驶舱

分析复盘→阶段驾驶舱，工作台有直接入口。选择起止日期，聚合阶段目标、已确认且标准可比的技能变化、严格同泳姿/测试项目/距离/池长的有效PB变化、实际训练及缺失量、已确认里程碑、待审核事项。每项可展开来源ID/版本和计算说明并跳回原记录。至少两条同口径有效成绩才显示变化，否则显示样本不足；不预测、不综合打分。日期外历史成绩只作基线并标明。

## 兼容、验收与回滚

共享严格合同及growthHistory覆盖新增三集合，兼容旧备份补空，恢复遗漏保留回收站/历史；台账迁移只放宽集合约束与同步白名单，sessions加列默认parent，旧会话仍有效。新集合已写入后保留宽约束和兼容后端，回滚优先关闭前端入口；不部署不认识新历史的旧API，不用旧快照覆盖新事实。

每阶段设计→RED/GREEN→完整NICO_TEST_PROTOCOL_ONLY=true npm run check→隔离PG/双后端/浏览器→提交推送→兼容迁移/Edge实际部署→合并master→Pages实际资源/API指纹/匿名边界/事实校验。生产不写协议儿童记录；保存私有备份和旧Edge源码。每阶段记录实际回执与人工待验，全部完成后一次独立全分支审查并修复重要问题。PDF/字体新增依赖核实官方资料并固定版本及许可证。
