# V1.4.1 生产质量收口设计

范围：以 ea0f3b1 为基线，仅完成 V1.4.1；V1.5 儿童视图、纪念册、归档包和驾驶舱暂缓。保留全部已有实体、事实计算、认证、公开授权及迁移约束。

## 差距与设计

| 事项 | 现状/差距 | 增量设计 | 风险/验收 |
| --- | --- | --- | --- |
| 后端部署 | 无凭据跳过仍绿色 | 依赖图确定性 SHA256；部署准备产生元数据；无凭据也必须查询实际在线 /api/version 与预期一致，否则失败 | 不以 CI 绿色替代部署回执；版本接口仅暴露程序版本，不含档案 |
| 前端部署 | 依靠人工比较资源 | build-info.json 保存前端提交及预期 API SHA256；发布核验同时比对页面产物和实际 API | 前后端提交可以不同，以 API 源码指纹判断兼容版本 |
| API 观测 | 无隐私安全统计合同 | 外层包装记录固定路由类别、状态、耗时、版本，结构化平台日志；私有健康接口提供本实例计数，明确冷启动重置 | 不记录路径 ID、查询、姓名、正文、令牌、素材地址；日志失败不得影响业务 |
| 页面观测 | 无统一异常计数 | 本设备内存计数：运行异常、API 分类、耗时、登录、上传/处理请求；私有设置内显示并可导出纯数字诊断 | 不保存异常信息、堆栈或业务内容；退出清空；不把实例计数当全站趋势 |
| 长期运维 | 无基线与恢复证明状态 | 只读审计脚本/查询与运维说明，分别记录日志基线、存储字节、备份时间、隔离恢复验证、版本与告警样本门槛 | 无自动备份调度则明示；样本不足不生成健康结论；不新增外部监控服务 |
| 安全 | 已有白名单/私有存储，需复核 | Nico 表/函数/存储权限只读审计；Git 历史仅路径/类型/敏感标记风险统计 | 不下载公开原始媒体、不删除历史、不更改共享模型权限 |
| 验收 | 协议测试较全、人工项未测量 | 复用现有跨本地/云协议及临时数据库测试；补部署、隐私指标及浏览器闭环；矩阵逐项列证据和限制 | 真人计时/手机/转码/PDF 打印/完整无障碍继续待验收 |

## 交互与页面

保持四入口、QuickEntry 和原有全部功能。账号菜单 → 管理设置 → 运行健康：显示“本设备观测”“当前后端实例”“版本核对”，每项说明时间范围和未知状态；只在已认证的完整管理视图加载。使用大触控按钮刷新及导出无隐私诊断，错误显示可重试，不隐藏事实页面或扩大访客范围。

## 版本合同

源码指纹由 Edge 入口及递归相对依赖（路径+内容）生成，排除唯一生成的版本模块以避免自引用。准备脚本同时生成部署模块和前端 build-info。公共 /api/version 只读返回 release、sourceHash、schema 合同版本；私有 /api/health 需现有有效家长登录。无凭据的 Actions 不假装已部署：只能验证已通过连接器部署的相同指纹，否则明确失败。手工连接器部署和 CLI 使用同一打包准备脚本。

## 观测边界

平台结构化日志用于跨实例观测；内存窗口用于即时排错，不宣称持久全站统计。备份/存储/历史恢复通过运维只读查询及隔离演练提供证据，未配置的自动恢复验证明确未知。告警先启用确定性版本不一致、匿名越权、备份缺失；错误率/延迟需足够生产样本后设定基线，协议样本不得充作生产基线。

## 发布与回滚

无破坏性迁移，无新业务集合。保存私有快照与旧 Edge 源码后发布。先部署兼容 API 并核对指纹，再推送合并 master，确认 Pages 实际资源及前后端一致；再次读取生产版本、内容校验、媒体数及公开摘要校验。回滚使用旧兼容源码或前端回退，保留全部真实事实与版本化历史；不回灌旧备份覆盖新记录。
