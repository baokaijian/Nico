# Nico Growth V1.3–V1.4 Implementation Plan

Goal: 在V1.2实体与四入口上增加可信的私有成长分析和长期档案。
Architecture: 纯只读投影 + 明确人工叙事实体，复用现有growth版本/历史/鉴权/CAS/幂等与公开白名单。
Tech Stack: React19/Vite8/Node/SQLite协议测试/Supabase既有JSON快照与私有存储；零新增运行时依赖。
Spec: ../specs/2026-10-23-v13-v14-growth-design.md
Global Constraints: 不生产写入、不破坏迁移、不重写训练/PB、不自动公开/授级、不伪造实际量；每阶段独立提交。
Review Focus: 来源失效、报告事实注入/过期、历史恢复、媒体鉴权、手工审核、计划实际量隔离。

## 1 数据质量与来源工作区
- RED tests/growth-quality.test.mjs：8类规则、空库/未知、可定位源集合/ID、失效引用。
- GREEN shared/data-quality.mjs `diagnoseQuality(data,day)` → {ruleId,collection,recordId,type,message,priority,targetRef?}[]。
- SourceWorkspace适配原详情/进入管理页；DataQuality组件；management/ManagementView接线。
- 针对测试、lint、build，记录风险/回滚，提交阶段1。

## 2 时间轴与故事
- RED tests/growth-timeline.test.mjs：有效PB逐项/历史、审核、过滤、关联媒体、故事生命周期。
- GREEN `growthTimeline(data,filters)`只聚合；archive-model新故事合同接入growth-model/records/domain，双后端CRUD自动复用，owner写入/请求重放。
- GrowthTimeline和安全身份草稿复用现有useGrowthForm或专用受限表单；独立确认动作。
- 历史/恢复测试、Supabase兼容集合扩展，文档，提交阶段2。

## 3 月/年报告
- RED tests/report-drafts.test.mjs + archive-api双后端：事实服务端、叙事编辑不改事实、过期/CAS/幂等、确认只读、旧备份恢复。
- GREEN `buildReportFacts(data,period)`、`reportBaseline(data,period)`、`reportStale(data,report)`、`growthReportHTML(report,stale)`；reportDrafts合同和服务端生成/refresh/confirm。
- Reports保留旧报告折叠入口，新增月/年草稿→编辑→预览→人工确认→导出，导出事实/来源/版本。
- 完整check、公网上包无新私有实体数据，提交V1.3。

## 4 赛事
- RED archive-api比赛日期/池长/性质/引用校验、历史保留、删除/恢复。
- GREEN competitionEvents合同、手动多选比赛成绩/影像/证书，复盘与奖项；无敏感位置/学校字段。
- UI/迁移白名单检查，提交阶段4。

## 5 视频A/B
- RED video-comparison纯同步偏移/时间校验、实际双视频和技能关联、私有接口未登录拒绝。
- GREEN videoComparisons合同；VideoCompare双私有blob、取消/撤销URL、起点偏移同步、速度与手动观察；复用版本草稿。
- 隔离小视频浏览器播放与错误场景，提交阶段5。

## 6 日历与综合验收
- RED calendar投影周/月、计划vs实际、休息/测试/评估/比赛、月份边界。
- GREEN TrainingCalendar和日期导航，无数据写入。
- AI仅强类型4类来源协议；产品需求/模型/验收/changelog与隐私计划更新。
- lint/typecheck/test/build/verifypublic；隔离UI保存、刷新、离线、冲突、退出、草稿恢复/跨模块；最终全分支fresh reviewer一次，修正重要问题一次。
- 提交各阶段；交付分支和真实待测项，未请求发布不操作生产。
