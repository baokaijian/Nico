# V1.4.1 实施计划

Goal：关闭 V1.4 已交付功能的部署、可靠性和验收状态缺口；本轮不实施 V1.5。

Architecture：复用 React/Vite/Supabase、19 集合和现有权限；新增确定性发布指纹、隐私安全观测包装、私有健康设置和只读运维证据。无业务数据迁移。

Tech Stack：Node >=24、React 19、Vite 8、Supabase Edge；复用Vite已有Rolldown解析器并显式锁定开发依赖；无新增运行时服务。

Spec：[设计](../specs/2026-10-24-v141-production-design.md)。Global constraints：只用协议样本/临时数据库测试；公开范围不变；CAS/幂等/历史/逻辑删除不变；不改共享项目其他模型。

## 顺序任务

1. 同步最新 master，保存只读线上版本、权限、内容摘要、备份和旧 Edge 源码；核对迁移历史。证据存 ignored review，公共文档只写计数及风险。
2. RED：新增 release-health.test.mjs，覆盖稳定指纹、依赖变化、实际部署不匹配失败、指标隐私/分类/上限及匿名健康接口拒绝。GREEN：scripts/release-info.mjs、prepare-release.mjs、verify-deployment.mjs；shared/runtime-health.mjs；cloud-api 和 Edge 入口包装；更新工作流。
3. RED：浏览器指标和会话清理测试。GREEN：src/services/health.js、HealthPanel.jsx、管理设置适配及全局异常采集；只存内存纯数字。
4. 完整 NICO_TEST_PROTOCOL_ONLY=true npm run check；现有跨协议业务闭环、恢复及隔离迁移演练；隔离浏览器验收训练到成绩、技能/目标人工确认、时间轴/报告/赛事/A-B/日历、失败/退出/草稿。对无法实际测量的项目明确待验。
5. 更新 requirements-gap、test-plan、changelog、生产验收记录及状态矩阵；一次独立最终审查，修复重要问题。提交推送功能分支，先通过连接器部署兼容 API 并核对源码/指纹，复核远端合并推送 master，等待 Pages/后端真实校验通过；再次校验线上资源、匿名边界及真实档案未改写。

Review focus：指纹不能凭空声称部署；无凭据必须校验实际 API；采集不能包含输入/路径/异常文字；健康接口不能匿名读；日志不能影响写入、CAS、幂等或媒体；不能用协议测试代表真人验收。

回滚：回退前端入口和健康包装，保留兼容 API、全部事实、历史和迁移；旧备份只用于隔离验证，不覆盖正式档案。
