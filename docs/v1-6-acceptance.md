# V1.6 可靠性增量交付与验收（2026-10-24）

## 范围与边界

按[可靠性设计](v1-6-reliability-design.md)实施第一期增量：离站加密、完整性校验、隔离恢复演练、发布一致性告警与脱敏监控的**可执行工具与测试**。真实离站目的地、恢复密钥保管人、外部通知渠道、定时调度与付费服务**仍未配置**；本期无新集合、无SQL迁移、无后端业务源码改动（Edge源码指纹保持 728cc4465d…，继续兼容复用API 1.5.2/Edge17）。不把工具就绪称作离站容灾已上线。

## 交付物

| 能力 | 文件 | 说明 |
| --- | --- | --- |
| 离站认证加密 | `shared/backup-crypto.mjs` | ECDH P-256 + HKDF-SHA256 + AES-256-GCM（仅WebCrypto，零新增依赖）；清单同样加密，逐文件SHA256，AAD绑定位置与文件名 |
| 完整性校验 | 同上 `openBackupPackage` | 错误密钥/篡改/缺条目/多余条目/过期分别按类别失败，不笼统报错 |
| 作业合同 | `scripts/backup-job.mjs` | keygen/seal/verify/rehearse 四类作业，回执只含运行标识、阶段状态、数量与摘要；输出目录禁止落在公开产物与真实档案目录 |
| 隔离恢复演练 | 同上 `runRehearsal` | 确定性协议样本→SQLite读取→加密→校验→四类反例→解密恢复→摘要一致；全程临时目录，零生产写入 |
| 发布一致性告警 | `scripts/verify-release-consistency.mjs` + `.github/workflows/deploy.yml` verify作业 | 部署后独立核对线上Pages资源、nico-build版本与实际API指纹；不一致使发布工作流失败（确定性告警通道），本地可单独执行 |
| 脱敏监控 | `shared/telemetry.mjs` | 固定白名单事件净化（封闭词汇、无URL/正文/堆栈）与永不阻塞业务的外发队列（失败重试、超限丢弃计数、心跳缺失可观测）；目的地未配置故未接线 |
| 存储/导出观测 | `scripts/storage-report.mjs` | 本地对象只读聚合与上期对比；单时点基线不设阈值，云端用 operations-queries 只读SQL |

`npm run backup:job rehearse` 可随时重复演练；`npm run release:consistency` 在本地构建后核对线上。

## 隔离验收（软件）

- 23项新增测试全绿：加密往返/错误密钥/篡改/缺条目/多余条目/过期/结构拒绝（7）；作业合同keygen/seal→verify/重复运行/损坏按类别失败/目录保护/空目录与超量/演练全绿/回执无内容（7）；脱敏白名单/错误报告/重试队列/心跳缺失/超限（4）；一致性全绿/资源不一致/版本不一致/网络不可达/缺清单拒绝（5）。
- 演练覆盖设计的反例集：加密→校验、错误密钥、篡改、缺卷、过期备份、重复运行、断网（fetcher不可达类别）；恢复内容与源摘要逐字节一致后才通过。
- 完整 `NICO_TEST_PROTOCOL_ONLY=true npm run check` 结果见发布回执；未向正式档案写入任何测试内容，未扩大公开授权。

## 启用门槛（未完成，不宣称达成）

1. 家长选定离站目的地/地区、恢复密钥保管人、费用上限后才配置真实密钥与上传；凭据不入仓库、Pages或公开日志。
2. 第一次正式导出需核对目的地与数据授权；此后开启有回执的计划作业、独立恢复演练与通知；阈值按真实运营周期观测后确定。
3. 脱敏监控接入私有目的地前保持未启用；服务端接入时须二次白名单净化。
4. 历史Git隐私清理、删除真实备份、用旧备份覆盖生产均需单独具体授权。
