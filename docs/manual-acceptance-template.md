# 真人与真实设备验收记录模板（V1.5.3）

本页是可执行模板，**全部初始状态为待验**。自动测试、合成素材和软件视口不等于真人验收。请复制到私人文件夹或忽略的 review/，勿将儿童原话、照片、地址、视频链接、账号和令牌提交公开仓库。

每次记录：验收人＿＿ 日期＿＿ 站点/前端版本＿＿ API版本/指纹＿＿ 设备/系统/浏览器＿＿ 网络＿＿ 使用真实业务资料还是隔离协议样本＿＿。

每个用例填写：开始/结束时间＿＿ 实测耗时＿＿ 操作结果＿＿ 保存版本/匿名化关联编号＿＿ 私有证据位置＿＿ 结论（待验/通过/失败/受阻）＿＿ 问题及复验日期＿＿。不得用预估耗时代替测量。

| 编号（当前均待验） | 操作步骤 | 应观察的结果与证据 |
| --- | --- | --- |
| R01 真人基础训练 | 家长登录→首次引导或记录训练→填写一次确实需要保存的日期、内容、实际时长或距离、完成情况→保存→结束→刷新。以开始填写至服务端成功反馈计时。附加成绩和视频可跳过。 | 熟练用户45秒是目标；记录实测值，未测不得达成。只保存1条，实际与计划分离，刷新可见。若无真实训练，改用隔离环境并标明不能完成真人业务验收。 |
| R02 手机及平板 | 各用一台真实设备完成登录、五步跳过/继续、待办筛选/原记录、编辑与返回、管理/查看切换、退出。横竖屏各测一次。 | 触控可用，键盘不遮挡保存，无页面横向溢出，刷新位置及登录符合有效期；记录实际设备，不能用桌面缩放代替。 |
| R03 视频 | 家长选择真实且需要入档的素材→上传→关联真实训练/成绩→播放原片及处理副本→检查处理失败和重试。 | 主事实不因上传失败撤销；关联正确；原片保留；实际编码、播放、耗时、文件大小与处理结果均记录。未获公开授权的访客不可读。 |
| R04 中文成长报告PDF | 选有真实资料月份/年度→预览事实与叙事→人工确认→下载PDF并在两个阅读器打开，另测浏览器打印。 | 中文无缺字、分页可读、来源与原值一致、默认私有；打印和直接PDF分别记录，软件字体测试不能代替。 |
| R05 年度纪念册 | 选已确认年度报告→选私有照片→编排叙事→预览/确认→导出PDF并打开。 | 选定照片实际嵌入，顺序/清晰度/分页可用；事实不受编辑影响。来源变化后提示过期、旧版保留。 |
| R06 归档分卷及SHA256 | 私人年度归档→按真实媒体规模分卷→逐卷下载；中断一卷后重试→独立解压读取JSON/CSV/报告与素材；逐一计算SHA256并与清单比较。 | 不漏卷、不重复、关联清单一致、媒体数量/字节/摘要匹配；失败卷可恢复，不在Pages存包。每卷私有证据记录卷号、数量、校验结论。Mac可用 shasum -a 256，Windows可用 Get-FileHash -Algorithm SHA256。 |
| R07 儿童受限会话 | 家长在设置明确选择内容→进入孩子页→填真实感受→返回家长→重新登录→单独审核；另测15分钟到期/撤销。 | 孩子仅能读授权投影，不能打开管理或其他原片；感受是待审草稿，不覆盖训练；家长凭据不沿用。 |
| R08 弱网/冲突 | 先在隔离环境演练飞行模式/弱网、提交响应丢失、两个窗口编辑同版本；恢复网络后按提示恢复草稿、重试、核对版本。真实网络用需要保存的业务资料另测。 | 不重复新建，失败输入保留，CAS冲突不静默覆盖；不能为了测试向正式档案造记录。记录网络条件、恢复动作与最终数量。 |
| R09 基础无障碍 | 键盘完成登录、引导、待办原记录和关闭弹窗；屏幕阅读器朗读标签/错误/进度；200%缩放、明暗和焦点可见性。 | 无键盘陷阱、焦点返回合理、标签与状态可理解。列明覆盖页与辅助工具；仅基础操作，完整无障碍仍需专门验收。 |

失败时保留原始资料与失败截图在私人位置，记录重现步骤并回报问题。不要为使清单通过而修改核验状态、技能等级或虚构训练。
