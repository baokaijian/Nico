# V1.7.0 录入与展示体验优化交付与验收（2026-10-24）

依据 [UX 回归走查](../review/UX_REGRESSION_2026-10-24.md)（私有）的四期优化方案实施，经用户确认全部推进，含第四期"按未知保留"裁决。

## 范围与实现

| 期 | 优化项 | 实现 |
| --- | --- | --- |
| 一 | 待办文案实体化 | admin-tasks 对 swim 待办生成"日期·项目（池长）"标题；DQ-SCORE-CONDITIONS 消息列出具体缺失条件 |
| 一 | 隐藏内部ID | TodoCenter 卡片与原记录工作区的 `collection/id` 折叠进"记录标识" |
| 一 | 按钮分层 | 录入表单与 QuickEntry 工具行的低频动作（导出草稿/刷新记录）收入"⋯"菜单 |
| 一 | 登录去预填 | 账号输入不再预填 admin |
| 一 | 触控目标 | 移动端按钮/输入/下拉/摘要≥44px，复选框≥24px 且行高≥44px |
| 一 | 时间易读辅注 | performance.ts 新增 readablePerformance：00:48:50 旁并列"（48.50秒）"，主显示与毫秒精度不变 |
| 二 | 原记录聚焦模式 | Records/TrainingRecords 聚焦时仅显示目标记录卡片+编辑，新增表单与筛选收纳，提供"在本类记录中查看全部"切换 |
| 二 | 链路成绩表单精简 | QuickEntry 链路内成绩主字段仅 日期/距离/泳姿/测试项目/池长/成绩，计时与条件（出发/计时/性质/有效性）折叠可选；打腿必选项目逻辑保留 |
| 二 | 技能标准直达 | 技能工作区空态旁提供"配置或审核技能标准"弹窗直达（复用向导模式），不再只靠账号菜单文字指路 |
| 三 | 分析复盘分组 | 子导航按 回顾/产出/素材/档案 四组展示，入口集合不变（测试保证覆盖一致） |
| 三 | 合并开始区块 | 引导未完成（<5/5）时工作台将引导进度与最要紧待办合并为单一"从真实资料开始"区块，独立待办栏隐藏 |
| 三 | 统一录入入口 | 训练记录页"记录本次训练"改为打开 QuickEntry 弹窗；内嵌表单默认折叠，编辑仍在原位 |
| 四 | 按未知保留裁决 | swim 记录新增可选 `conditionsKeptUnknownAt/By`（日期+≤50字裁决人）；裁决后 DQ-SCORE-CONDITIONS 不再催办；条件补齐为明确值时裁决自动失效；成绩数值、有效性、PB 参与规则、公开范围均不变 |

## 后端与数据影响

- domain.mjs（Edge 依赖图内）校验白名单新增两个可选字段并做形状校验；**Edge 源码指纹由 728cc4465d… 变为随本版部署的新指纹**，需要重新部署 `nico-api`。旧函数源码与回执已存 `review/V17_OLD_FUNCTION_SOURCE/`（私有），回滚用前端回退+兼容后端保留，不以旧源码覆盖新事实。
- 无新集合、无 SQL 迁移；本地服务与云函数共用同一校验，PUT 部分更新沿用 CAS/幂等；备份、导出、公开摘要不受影响（裁决字段不进入公开投影）。

## 软件验收

- 新增 tests/v17-ux.test.mjs 7 项：实体标题、缺失明细与豁免、裁决字段校验（非法日期/缺裁决人/超长拒绝、清空、不改成绩事实）、条件补齐自动失效（修复开发中"空数组真值"笔误后通过）、易读辅注、复盘分组覆盖一致、云端协议 PUT 裁决落库与 409 重放保护。
- 完整检查 220/220 通过（含既有 213 项全量回归）、lint 0 警告、构建与公开白名单通过。
- 隔离协议环境（5294，合成媒体）浏览器回归：登录无预填；工作台合并开始区块+实体待办标题；原记录聚焦模式（单卡片、无表单无筛选、记录标识折叠、查看全部切换）；按未知保留裁决保存后"计时条件缺失"待办即时消失并显示裁决说明；链路训练→摘要→成绩（6 主字段+条件折叠）→结束全程闭环且摘要带易读辅注；训练页"记录本次训练"统一打开 QuickEntry 弹窗且内嵌表单收起；分析复盘四分组；移动端 390px 无横向溢出、无 <24px 触控目标。零生产写入。

## 人工待验与回滚

真机/真人验收仍按[九类模板](manual-acceptance-template.md)执行，软件视口不代替真机。"按未知保留"属产品语义新增：裁决只隐藏催办、不改事实，且留有裁决人与日期审计线索。回滚回退本期提交并保留已部署兼容函数与已产生的新字段（旧前端忽略未知字段），不删除家长已做的裁决记录；如需回退函数，参照 review/V17_OLD_FUNCTION_SOURCE 于确认后单独执行。
