- 本机与云端 API：完整快照、全部集合、原片、备份、预览和写入均需会话；公开媒体仅接受实时人工白名单。本机公开读取改用事实库白名单，独立静态服务保持兼容。
- 构建与校验：配置云 API 时不复制静态成绩/影像；独立静态模式仍使用已确认 release。Edge 工作流先运行检查，修复 secret 条件表达式并增加发布后权限验证。

- 移动端：关闭的侧栏不再进入键盘/读屏导航；支持 Escape 关闭侧栏。
- 已执行：lint、67 项单元及接口测试、静态和云端构建、两种产物白名单检查。浏览器桌面及 390×844 手机视口无横向溢出；公开授权视频元数据可读；隔离环境首次改密前没有私有快照请求，改密后可进入管理，退出回到公开摘要，令牌未写入浏览器持久存储。
- 兼容/回滚：新增非破坏性台账补丁，为已有薄弱点/打卡扩展集合约束和同步支持，不修改业务快照、版本或媒体；旧九集合快照可直接读取。旧备份恢复不丢后续计划快照。回滚保留权限边界、扩展台账与历史保护；不可回退到匿名完整读取。真实管理员密码未改动。
- 仍待实施：TypeScript/typecheck、整数毫秒迁移与有效性、实际训练组/模板、幂等与审计、技能模型、完整目标/成长档案/报告。真人 60 秒录入和完整 WCAG 2.2 AA 尚未验收。

## 2026-10-21 — V1.0 第二阶段：整数毫秒与成绩有效性

- 新增共用 TypeScript 成绩核心、严格 tsconfig 及 `typecheck`，接入现有完整检查；保留原 JSX/MJS 框架，不同时重写界面。
- 以 `timeMs` 及可选比较成绩毫秒保存精确值，保留精确输入与旧展示字段；显示仍为 `00:56:17`，支持三位小数输入和必要的小时字段，改备注及旧客户端提交同一展示值不会截断精度。
- 增加未核验/有效/失格/无效和依据字段。PB、差距、改善率、趋势、报告及打卡分析统一使用有效、同项目、明确池长的整数值；不把旧记录自动认定有效，不删除失格或无效历史。单样本不计算改善，不放大1毫秒差异的图形。
