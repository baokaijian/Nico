# 历史隐私清理执行方案（仅方案，未执行）

本轮没有删除真实内容、撤回原授权素材或重写Git历史。公开展示范围沿用现有白名单。

1. 先只读盘点：当前发布包、公开存储、Git全部引用/标签与文档中的学校、精确地点、身份和凭据。清单只列路径、内容类型、仍否公开，不复制个人信息或密钥原文。
2. 留存恢复点：导出完整档案、回收站、成长/计划历史、素材校验清单与当前Git引用。备份保存在家长控制的私有位置，验证可恢复。
3. 家长逐项决定：保留公开、撤回白名单、替换脱敏副本，或需要处理历史。修改授权范围与删除原事实分开审批，不把“停止公开”解释成“删除档案”。
4. 普通撤回：仅在获得具体授权后取消对应公开项并重新发布，检查公开摘要和旧素材URL；私有原片及审计历史保留。已下载、第三方缓存与fork不能保证收回。
5. Git历史重写：另外列明受影响分支、标签、协作者、force-push和不可逆影响，获得明确授权。先在独立镜像演练、验证备份、准备旧引用恢复方案；泄露凭据应按独立授权先轮换，而不能只删文字。
6. 执行与复验：核对公开包/匿名读权限/敏感字段与素材链接；把执行人、时间、授权范围和验证结果写入私有审计。未经第3/5步具体确认，不执行删除或历史重写。

此方案不承诺清除第三方已经保存的副本，不把逻辑删除误作永久删除。
