# Nico Growth 产品要求

用户：家长管理员维护真实训练与成长档案，访客只读公开概览、成绩和授权影像；可选协作角色属于后续版本。沿用现有页面结构和 GitHub Pages 入口，完整档案由认证后端读取。登录不是公开页浏览的前提。

1. 首页只展示有依据的能力、训练、阶段目标、PB 和成长事件。未测评显示未测评，样本不足不绘制预测。
2. 训练支持快速记录与实际完成组、模板和复制；组距离×实际完成次数汇总实际距离，计划量独立。保留感受、备注、教练反馈和影像关系。
3. 成绩保存项目、池长、计时方法、类型、有效性、日期和证据；整数毫秒为标准值，显示 `mm:ss:cc`。同泳姿/距离/池长且有效才参加 PB；失格、无效不计入。原始输入保留以便追溯。
4. 技能模型仅为内部成长记录，八维 L1–L5 标准由家长配置确认；评估必须有评估人、日期和依据，关联训练/媒体，保留冻结标准与版本历史；打卡不自动授予等级。
5. 目标支持成绩、技能、习惯、比赛、自定义，记录起始/目标状态、日期、标准、计划、实际完成。V1.1状态为待确认、进行中、已达成、暂停、已归档；达成证据需人工确认，归档保留确认信息。
6. 媒体默认私有，家长明确勾选才能公开；支持撤回。上传保留原片和处理失败重试。标签、时间点、对比和教练评语不自动成为公开字段。
7. 成长档案支持真实技能首次完成、PB、比赛、训练里程碑、奖项、感想与观察；月年报告可编辑后导出。
8. 分析提供周/月/年真实次数、分钟、实际距离、泳姿占比、计划达成、PB、技能、目标和里程碑；每项解释口径和缺失条件。
9. 所有修改在服务端鉴权、验证关联与版本；重复请求不重复建档；逻辑删除可恢复，恢复不丢失更新后的历史。备份与导出须登录。
10. 移动端常用入口清晰、可键盘操作，有加载/空/错误/保存反馈。60 秒基础训练录入是验收目标，须真人计时后才可宣称达成。

V2 的 AI 只可生成待确认文字或辅助建议；不生成运动事实、技能等级、医疗判断、安全认证和无依据预测。

第三阶段训练验收口径：实际计次需填写正的实际距离/时长，或家长明确标记已完成/部分完成；记录数量另列。取消及未完成不计实际量。实际次数缺失不按计划次数补齐，已知部分与完整总量分开显示。计划记录覆盖率按去重关联课次/当前确认计划课次数计算，有明确版本的旧版记录不计新版；版本未知的历史ID只能计记录覆盖，不能计人工确认完成。人工确认完成率仅取标记已完成且版本匹配的去重关联课次，二者不混称。模板仅供复用家长自己的安排，没有内置训练处方。

## V1.3–V1.4 增量（2026-10-23上线）

四入口、QuickEntry、训练模板及稳定计算沿用V1.2。分析复盘新增私有数据质量、成长时间轴、月年报告和视频对比；训练记录新增赛事和周/月日历。诊断八类问题并进入原记录；故事、报告独立人工确认，不自动公开。报告服务端冻结事实，叙事可编辑；来源变化标过期，确认后不覆盖。赛事手动多成绩和证书关联；A/B只记录真实人工观察，不授级。日历区分计划、休息和实际。AI仅来源化的四类待确认扩展协议，无模型服务。

设计、差距、来源口径与历史隐私清理计划见[设计](superpowers/specs/2026-10-23-v13-v14-growth-design.md)；分阶段风险、验证和回滚见[验收](V13-V14-ACCEPTANCE.md)。不执行历史隐私清理。

## V1.5.2 私人成长体验（2026-10-24）

- 儿童页：家长选择主题/照片并显式开启当前标签页15分钟受限会话，仅查看已确认成长/PB/里程碑/故事，原话和心情独立待家长确认；不写训练事实，不自动公开。交还需重新登录，关闭其他已授权管理标签页后交接设备。
- 年度纪念册：基于已确认年度报告及冻结来源版本，允许主题/编排/原话，确认和过期保护独立；本机PDF可嵌入兼容精选照片，视频仅私有索引。
- 私人归档：年度JSON/训练成绩CSV/PDF/相关历史及关联清单、明确选择的媒体文件、分卷SHA256清单；未知/失败/源变化显示缺口，取消与会话隔离。年度包不作整库覆盖恢复，不在公开站点存包。
- 阶段驾驶舱：实际量、严格可比有效PB、明确同标准确认复测、当前目标及已确认里程碑/待审核事项，每项来源可查；不预测、评分或儿童排名。

软件183项完整检查通过，实际发布及边界见V1.5验收。阶段二至四新交互、真实手机/45秒真人录入/真实转码/PDF打印和完整无障碍仍待验，不能因软件测试成功而改为真人已验收。

## V1.5.3 真实启用与管理效率

入口保持四项：工作台新增首次使用引导、待办中心子页。五步为历史成绩核验、真实技能标准与基线、首次实际训练、既有目标、影像关联。跳过只记本机偏好，完成由真实数据推导；空集合不代表未训练或无能力。所有录入复用原组件和权限。

工作台与待办共用纯投影，覆盖核验、测评、孩子感受、目标、里程碑、过期报告/纪念册、失效媒体及引用。类别和优先级可筛选，每项打开精确原记录；不新增事实实体或批量确认。

访客成绩为已核验/PB及全量授权历史两区；没有有效记录的项目不占PB卡片。不改变既有公开授权、有效性及精度。私人引导/待办不进入访客摘要。验收模板和V1.6运维设计独立交付，真实设备和操作尚待家长验收。
